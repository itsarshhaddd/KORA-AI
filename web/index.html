KORA

Knowledge Oriented Response Assistant

A local general-purpose assistant that can use your workspace when relevant. Your files, index and chat history stay on this computer.

Fully localThe model and embeddings run on your machine.
Workspace-awareKORA can search indexed documents when your question needs them.
Source-awareWorkspace answers can show the records used to answer.

How an answer is made

  1. Understand the questionThe local model decides what information it needs.
  2. Use tools when neededKORA can search documents, read a document, list files, use conversation context and calculate.
  3. Write the answerThe local model turns the results into a normal response.
  4. Show workspace sourcesWhen indexed records are used, their source metadata is shown below the answer.
